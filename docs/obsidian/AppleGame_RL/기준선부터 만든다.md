# 기준선부터 만든다

**핵심**: 학습 모델을 평가하기 전에 단순 규칙의 점수부터 잰다. 그래야 모델이 무엇을 배웠는지 말할 수 있다.

**내용**
- 사과게임: 무작위(유효 수) 103점, 탐욕(사과를 가장 적게 지우는 수) 114점.
- 이 기준이 없었으면 "PPO 112점"을 성공으로 착각했을 것이다. 실제로는 단순 규칙보다 낮은 점수였다.
- 비교는 반드시 **같은 보드 묶음**(시드 고정)과 **표준오차**를 함께 본다. 100판 기준 +1.2점 차이는 1000판에서 사라졌다.
