# 범용 OCR 대신 템플릿 매칭

**핵심**: 글꼴과 위치가 고정된 화면(게임 UI)은 범용 OCR보다 템플릿 매칭이 빠르고 정확하다.

**내용**
- 격자 찾기: 빨간 픽셀을 행/열로 투영해 사과 줄과 칸 구간을 찾는다.
- 숫자 읽기: 칸 안쪽 원에서 흰 픽셀만 잘라 10×14로 정규화한 뒤, 숫자 1~9 평균 템플릿과 거리를 비교한다. 1등과 2등의 거리 차이를 신뢰도로 쓴다.
- 함정: 고해상도 화면에서 사과 꼭지(갈색)가 별도 줄로 잡혀 행이 20개가 됐다 → 최대값 대비 기준과 짧은 구간 제거로 해결.
- 디자인이 두 가지라 템플릿을 디자인별로 모아 최근접 비교했다.
- 검증은 홀드아웃으로 했다 (템플릿에 쓰지 않은 보드로 정확도 측정). 결과: 70가지 중 69가지 100%.
