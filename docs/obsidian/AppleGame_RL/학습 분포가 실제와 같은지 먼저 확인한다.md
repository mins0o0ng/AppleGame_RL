# 학습 분포가 실제와 같은지 먼저 확인한다

**핵심**: 생성한 학습 데이터가 실제와 다르면, 생성 데이터에서 잰 성능은 실전 성능이 아니다.

**내용**
- 처음에는 1~9 균등 무작위 보드를 가정했다. 실제 스크린샷 10장을 분석하니 숫자 합은 항상 10의 배수였고, 게임 버전이 두 가지였다.
  - 둥근 사과: 작은 숫자가 많고 배치에 구조가 있다. "빈 사각형 안 2~3칸에 합 10 채우기" 역순 생성으로 재현했다.
  - 납작한 사과: 균등 분포에 가깝다.
- 생성 보드로 학습한 AZ 모델은 생성 보드에서 +6점이었지만 실제 보드에서는 0점 수준이었다. 분포 차이에 취약했다.
- 확인 방법: 실제 샘플 몇 개로 숫자 분포(카이제곱), 합 조건, "숫자를 섞은 보드"와 비교(배치 구조 여부)를 본다.
