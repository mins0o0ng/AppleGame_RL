# 결과를 계산할 수 있으면 학습보다 탐색

**핵심**: 보드가 정해지면 운이 없는 게임(결정적 게임)에, 빠르고 정확한 시뮬레이터까지 있으면 각 수를 끝까지 둬 보는 탐색이 학습된 추정보다 강하다.

**내용**
- 롤아웃 탐색: 모든 후보 수를 둬 보고, 각각 탐욕 규칙으로 끝까지 진행해 최종 점수가 가장 높은 수를 고른다. 학습이 필요 없다.
- 균등 보드: 롤아웃 130 > PPO+빔 125.6 > AZ+MCTS 124.3. 실제 보드: 롤아웃 130 > MCTS 121.
- AlphaZero의 MCTS는 가치망이 정확할 때만 강하다. 탐색 횟수를 4배로 늘려도 +1.7점에 그쳤다. 가치망 정확도가 상한이었다.
- 반례 조건: 시뮬레이션이 느리거나, 운이 섞이거나, 계산 시간 제한이 매우 짧으면 학습된 정책/가치가 유리할 수 있다.
