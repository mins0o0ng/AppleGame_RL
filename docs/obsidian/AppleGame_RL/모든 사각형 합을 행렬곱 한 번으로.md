# 모든 사각형 합을 행렬곱 한 번으로

**핵심**: 고정된 격자에서 모든 직사각형의 합이 필요하면, (칸 × 사각형) 포함 행렬과 행렬곱 한 번으로 계산할 수 있다.

**내용**
- 10×17 판의 사각형은 8,415개다. 보드 (N, 170) @ 포함 행렬 (170, 8415) = 모든 사각형의 합.
- 2D 누적합 + gather보다 CPU에서 약 15배 빨랐다. 메모리 접근이 단순하고 BLAS를 쓰기 때문이다.
- 같은 방식으로 사과 개수, 네 변에 사과가 있는지(꽉 끼는 사각형) 판정, 정책 헤드(칸 점수 → 사각형 점수)까지 계산했다.
- 결과: 환경 속도 약 10,000 스텝/초 (CPU 4코어).
