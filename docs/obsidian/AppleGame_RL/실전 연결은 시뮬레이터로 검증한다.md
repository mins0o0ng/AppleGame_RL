# 실전 연결은 시뮬레이터로 검증한다

**핵심**: 실제 환경에 접근할 수 없을 때는 실제와 같은 규칙의 가짜 환경을 만들어 끝까지 돌려 본다. 그리고 실제에서 나온 실패는 가짜 환경에서 재현한 뒤 고친다.

**내용**
- 가짜 화면: 스크린샷을 큰 캔버스에 붙이고, 드래그한 상자 안 합이 10이면 사과를 배경색으로 지운다.
- 가짜 웹페이지(`mock_game.html`): 신뢰된 입력(isTrusted)만 받게 해서 Playwright 입력을 검증했다.
- 실제에서 나온 문제와 대응:
  - 드래그가 반영 안 됨 → 누른 뒤 멈춤, 단계별 이동
  - 행 20개 인식 → 확대 이미지로 재현 후 수정
  - 1수에 153점 집계 → 계획한 칸만 사라졌는지 매 수 검증
  - 마지막 수 미집계 → 종료 창과 마지막 수를 구분
- 매 수 기록(`play_log.txt`)을 남기면 실제 실패를 다시 따라가 볼 수 있다.
