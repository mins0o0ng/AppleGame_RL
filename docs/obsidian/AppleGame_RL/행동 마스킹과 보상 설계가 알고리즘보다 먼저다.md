# 행동 마스킹과 보상 설계가 알고리즘보다 먼저다

**핵심**: 강화학습이 실패하면 알고리즘(PPO vs DQN)을 바꾸기 전에 행동 공간과 보상부터 의심한다.

**내용**
- 사과게임 v1은 8,415개 행동 중 유효한 수가 약 0.65%뿐인데 마스킹이 없었다. 학습 시간 대부분이 "합이 10인 사각형 찾기"에 쓰였다.
- "합이 9나 11이면 +0.5"라는 근접 보상 때문에, 보드를 바꾸지 않는 같은 행동을 반복해 보상을 받는 구멍(reward hacking)이 생겼다.
- 마스킹을 넣자 무작위로만 둬도 103점이 나왔다. v1 PPO가 4~5시간 걸려 배우던 것을 코드 몇 줄로 해결한 셈이다.

**적용**: 유효 행동이 희소하면 마스킹(MaskablePPO 등). 보상은 실제 목표(지운 사과 수)와 같게.
