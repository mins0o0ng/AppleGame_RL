# 신호 대 잡음으로 강화학습 실패를 진단한다

**핵심**: "학습이 안 된다"를 한 수의 효과(신호)와 결과의 흔들림(잡음)으로 수치화하면 원인과 해결 방향이 보인다.

**내용**
- 측정 결과: 첫 수를 최적으로 바꾸면 +13.7점 (개선 여지는 있음). 그러나 보드 간 점수 흔들림 ±15.4, 같은 보드에서 확률적으로 플레이할 때 흔들림 ±6.0.
- 한 수의 평균 효과(약 1점)가 운에 묻힌다. PPO는 이걸 구분하려면 판 수가 엄청나게 많아야 한다.
- 결론: 하이퍼파라미터를 조정할 게 아니라, 신호 자체를 바꿔야 한다 (모든 후보를 같은 조건에서 비교하는 탐색).
